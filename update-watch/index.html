Update Watch

Is it safe to update? Before you run docker compose pull on Nextcloud, Immich, Jellyfin, n8n, Vaultwarden or Home Assistant (Container): we already did - on a throwaway machine, with real images and test data in it (users, files). (RSS feed coming soon)

How a verdict is made

  1. A new release appears (checked every night).
  2. A fresh test machine starts the PREVIOUS version and fills it with data (users, files).
  3. A consistent data snapshot is taken with the free safe-update tool.
  4. The update runs; the app must come back with the same data.
  5. The snapshot is restored in a separate copy - proof you can go back.

GREEN all of that worked · YELLOW works with a step first (e.g. an intermediate version) · RED the update or the way back failed in our test.
