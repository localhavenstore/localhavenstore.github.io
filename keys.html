Release signing keys

Localhaven signs the release files of its free tools with minisign. Each public key is printed in two places - in the project's README on GitHub and on this page - so one hacked page is not enough to trick you. Before you run anything, check that both places show exactly the same key.

Check a download (Ubuntu: sudo apt install minisign):

minisign -Vm SHA256SUMS -P RWRm811iTQFRJDr+KMkiTDBv0FiIz9owb6TzcHOD1qZrohmHulCk8m6I
sha256sum -c SHA256SUMS

The project README has the full, safer install steps (verify as root in a root-only folder first).
